Day 3 — Create Subnet

Completed November 14, 2026

Nautilus migration scenario: create one subnet named xfusion-subnet in the default VPC (us-east-1). The task specified no CIDR block — any valid, non-overlapping block inside the VPC range works.

Step by step:

  1. Work through candidate CIDR blocks in the console — several bounce because they overlap existing subnets or aren't valid block boundaries.
  2. Land on one that takes: 172.31.110.0/20.
  3. Create the subnet with that block.

What it taught: /20 blocks align on third-octet multiples of 16 (0, 16, 32, 48…), and each spans 16 numbers — 110 sits inside the free 96–111 block, which is why it worked. Method for next time: read the existing subnets list first, find the missing multiple of 16, use it directly. (Done solo, at her own choice.)
